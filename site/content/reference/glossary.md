# 用語集

| 用語 | 意味 |
| --- | --- |
| **Bot トークン** | Bot が Discord にログインするための秘密の文字列。パスワードと同じ扱いです。 |
| **Gateway** | Discord が Bot にイベントを送ってくる常時接続。Akari が自動で管理します。 |
| **Intent** | Bot が受け取りたいイベントの種類。必要なものだけ要求します。 |
| **Message Content Intent** | メッセージの本文を読むための特別な Intent。Developer Portal で有効にします。 |
| **ギルド（guild）** | Discord API での「サーバー」の呼び名。 |
| **Interaction** | スラッシュコマンド、ボタン、選択メニュー、フォーム送信など、ユーザーの操作を表すイベント。3 秒以内の応答が必要です。 |
| **ephemeral（エフェメラル）** | 操作した本人にだけ見えるメッセージ。 |
| **defer** | 「処理中」を先に表示して、3 秒の期限を延ばす応答。あとで結果を返します。 |
| **followup** | 最初の応答のあとに送る、追加のメッセージ。 |
| **custom_id** | ボタンや選択メニュー、フォームを見分けるための、自分で決める文字列（1〜100 文字）。 |
| **Embed** | タイトル、説明、色、項目を持つ、カード型のメッセージ部品。 |
| **Components V2** | テキストやコンテナーを自由に並べられる、新しいメッセージの形式。従来の本文や Embed とは併用できません。 |
| **モーダル（Modal）** | 画面の中央に開く入力フォーム。 |
| **ハイブリッドコマンド** | 1 つの関数を、テキストコマンドとスラッシュコマンドの両方に登録したもの。 |
| **Twilight** | Akari の土台になっている Rust 製の Discord ライブラリ。 |
| **Tokio** | Rust の非同期ランタイム。`async fn` を動かします。 |
| **クレート（crate）** | Rust のライブラリやプログラムの単位。Akari は `disnana-akari` クレートです。 |
